## 0. 摘要

本轮把"原始数据 → 12 个成长因子 → IC / 分层检验"的全链路跑通，产出 12 个因子的月频面板和首轮检验结果。

**核心数字**：519,860 行原始数据 → 445,724 行合格样本（5,317 只股票）→ 72 个截面 → 12 个因子；耗时 24.7 秒，峰值内存 456 MB；13 个测试全部通过。

**首轮结论**（详细见第 6 节）：

- 当季（q）因子有正向选股能力：ROE_G_q 多空年化 +5.0%、单调性 +1.0；
- TTM 因子接近失效，三年复合因子**显著反向**（Profit_G_3y 多空 -4.1%）；
- 因子效果高度依赖年景：2020、2024 很强，2021、2023 失效。

**本轮修复的关键 bug**：分层代码把第 0 层实现成了"因子最低组"，导致多空方向整体取反，已修复并加回归测试。

## 3. 结果是怎么算出来的

### 3.1 因子构建（`src/factors.py`）

先转宽表（`date × instrument`），再用 `shift(12)` / `shift(36)` 取去年同期：

| 因子 | 输入字段 | 基期 | 公式 |
|---|---|---|---|
| `Sales_G_q` | `operating_revenue_mrq` | t-12 | `(X_t - X_{t-12}) / \|X_{t-12}\|` |
| `Sales_G_ttm` | `operating_revenue_ttm` | t-12 | 同上 |
| `Sales_G_3y` | `operating_revenue_ttm` | t-36 | `(X_t / X_{t-36})^(1/3) - 1` |
| `Profit_G_q` | `net_profit_mrq` | t-12 | 同 q 公式 |
| `Profit_G_ttm` | `net_profit_ttm` | t-12 | 同上 |
| `Profit_G_3y` | `net_profit_ttm` | t-36 | 同 3y 公式 |
| `OCF_G_q` | `net_cffoa_mrq` | t-12 | 同 q |
| `OCF_G_ttm` | `net_cffoa_ttm` | t-12 | 同上 |
| `OCF_G_3y` | `net_cffoa_ttm` | t-36 | 同 3y |
| `ROE_G_q` | `net_profit_mrq / 净资产` | t-12 | 先算 ROE 再同比 |
| `ROE_G_ttm` | `net_profit_ttm / 净资产` | t-12 | 同上 |
| `ROE_G_3y` | `net_profit_ttm / 净资产` | t-36 | 先算 ROE 再复合 |

**三个口径约定**：

1. 增长率分母取绝对值 `|base|`，避免亏损转盈时符号翻转；
2. 三年复合要求 `cur > 0` 且 `base > 0`，否则 NaN；
3. 财报 0 填充视为缺失：营收 `<= 0`、利润/现金流 `== 0`、净资产 `<= 0` 全部置 NaN（`sanitize()`）。

### 3.2 预处理（`src/preprocess.py`）

对每个截面（每个月末）依次做：

1. **去极值**：`median ± 5 × MAD`；
2. **行业中性**：减去同行业均值；
3. **标准化**：z-score。

> 注意：P1 阶段**没有做市值中性**。原文 IC 要求"对市值因子及行业因子做线性回归取残差"，
> 从 P2 起才补齐（对行业哑变量 + ln 流通市值回归取残差）。因此本报告的 IC 与分层，
> 与最终的 `fdr_summary.csv`、`report_layer.csv` 存在系统性差异。

### 3.3 下月收益

```python
fwd = close.pct_change(1).shift(-1)
```

`close` 是后复权价，所以收益率包含分红再投资。最后一个月没有下月收益，因此 IC 只有 71 个月（72 个截面 − 1）。

### 3.4 IC 计算（`src/evaluate.py::ic_series`）

逐月计算因子值与下月收益的 Spearman 相关：

```
IC_t = corr_rank(f_{i,t}, r_{i,t+1})
```

- 要求当月有效股票 ≥ 30 只；
- 汇总指标：IC 均值、标准差、IR = 均值/标准差、IC>0 占比、t 值 = 均值/标准差×√n。

### 3.5 分层回测（`src/evaluate.py::layer_returns`）

1. 每个月末在**每个行业内部**按因子值排序；
2. 按分位数切成 5 层（`layer 0` = 因子最高组）；
3. 层内等权，计算下月平均收益；
4. 多空 = 第 0 层 − 第 4 层；
5. 单调性 = `−spearman(层号, 各层平均收益)`，+1 表示完全单调、高因子组最优。

### 3.6 绩效指标（`perf_stats`）

| 指标 | 公式 |
|---|---|
| 年化收益 | `(1 + 月均收益)^12 − 1` |
| 年化波动 | `月收益标准差 × √12` |
| 夏普 | `年化收益 / 年化波动`（rf=0） |
| 最大回撤 | 净值 / 历史最高 − 1 的最小值 |
| 胜率 | 收益 > 0 的月份占比 |

## 8. 本轮发现并修复的问题

**分层方向错误**

- 现象：初版 `ROE_G_q` 多空年化 -5.2%，与 IC 为正矛盾；
- 原因：`assign_layers` 用 `rank(pct=True)` 升序后直接分桶，导致 `layer 0` 是因子**最低**组；
- 修复：改为 `layer = (n-1) - min(int(pct*n), n-1)`，使 0 层为最高组；
- 影响：修复后 `ROE_G_q` 多空从 -5.2% 变为 +5.0%，所有符号恢复一致；
- 守卫：新增 `test_layer_direction`，断言 `layer 0` 的因子均值 > `layer 4`。

> 这个 bug 不会报错、不会让测试失败，只会让所有结论反向，属于最危险的一类。初版结果已作废，`output/` 下为修复后数据。

## 9. 与原文的关系

| 原文结论 | 本次结果 | 判断 |
|---|---|---|
| 当季 > TTM > 三年 | q 因子正、3y 因子负 | **方向一致且更极端** |
| Profit/ROE > Sales > OCF | ROE/Profit 最强，OCF 居中，Sales 最弱 | 部分一致；OCF 在统计上反而最显著 |
| 成长因子整体弱于估值 | 未做估值对比 | 不适用 |
| 3y 因子"基本无效" | 3y 因子显著反向 | 不一致，值得单列一节 |

**差异的可能原因**（待 P2/P3 验证）：

1. 样本期不同：2016 年后注册制、退市新规、机构化改变定价；
2. 2021 年基数效应：低基数推高同比，高增长股估值透支；
3. 风格切换：2021–2024 红利/低估值占优，高成长被系统性抛弃。

| 局限 | 影响 | 计划 |
|---|---|---|
