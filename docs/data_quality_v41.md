## 2. 发现的问题

### 问题 1：北交所 2025-10 起数据断档

| 月份 | 股票数 |
|---|---|
| 2025-09 | 5,678 |
| 2025-10 | 5,444（少 243 只） |

抽查缺失的 243 只：**242 只是北交所**。即北交所数据只到 2025-09。

**处理**：全样本剔除 `is_bj == 1`。理由不只是断档——北交所 2021-11 才开市，流动性与主板差异大，纳入会污染分层与 IC。剔除后 2025-10 的股票数恢复正常。

### 问题 2：涨跌停事件表 97.8% 是无效行

`limit_events.csv` 有 **10,316,865 行 / 226 MB**，但 `price_limit_status` 的语义是：

| 状态 | 含义 | 行数 |
|---|---|---|
| 1 | 涨停（`close == upper_limit`） | 70,826 |
| 2 | **正常交易**（有涨跌幅限制但未触及） | 10,087,230 |
| 3 | 跌停（`close == lower_limit`） | 158,809 |

我导出时用了 `!= 0`，把"正常"也带上了。真正有效的是 **229,635 行**，已过滤为 `limit_events_valid.csv`（约 5 MB）。

### 问题 3：633 条月度收益超过 100%

集中在次新股上市初期与少量复权基数异常。

**处理**：入池条件加"上市满 12 个月"（`list_days >= 365`），再做中位数 5 倍去极值。这两个动作也是研报的做法（剔除次新影响），需在报告中注明。

### 问题 4：沪深300 指数缺失（唯一硬缺口）

预检发现平台**有**指数表 `cn_stock_index_bar1d`（13 列：date/instrument/name/open/high/low/close/volume/amount/change/change_ratio/turn），但 v4.1 只做了探测、没有导出。

**需要补导 000300.SH 的月频收盘**，约 120 行，30 秒即可。脚本见第 4 节。

## 4. 待补：指数导出脚本（30 秒）

在平台新建一个 cell 运行，产出 `index_000300_monthly.csv`，和 `bq_export_v41/` 放一起：

```python
import dai, pandas as pd

START, END = "2016-01-01", "2025-12-31"
sql = f"""
SELECT date, instrument, name, close, change_ratio
FROM cn_stock_index_bar1d
WHERE instrument = '000300.SH'
  AND date >= '{START}' AND date <= '{END}'
ORDER BY date
"""
df = dai.query(sql, filters={"date": [START, END]}).df()
df["date"] = pd.to_datetime(df["date"])

# 取每月最后一个交易日
last = df.groupby(df["date"].dt.to_period("M"))["date"].max().values
m = df[df["date"].isin(set(last))].copy()

m.to_csv("index_000300_monthly.csv", index=False, encoding="utf-8-sig")
print(m.shape, m["date"].min(), m["date"].max())
print(m.head())
```

预期输出约 120 行、2016-01 至 2025-12。

## 5. 处理后的入池规则（确认版）

综合研报口径与本次数据实际情况：

| 条件 | 规则 | 理由 |
|---|---|---|
| 板块 | 剔除北交所（`is_bj == 1`） | 数据断档 + 流动性差异 |
| ST | 剔除 `st_status > 0` | 研报口径 |
| 停牌 | 剔除调仓日停牌（月末 `suspended == 1`），次日停牌用事件表补判 | 研报口径 |
| 次新 | `list_days >= 365` | 规避上市初期异常收益 |
| 缺失 | 因子值或市值缺失则剔除 | — |
| 去极值 | 中位数 ±5×MAD | 研报口径 |
| 标准化 | z-score | 研报口径 |
| 行业 | 申万2021 一级，31 类 | — |

剔除北交所后，2020–2025 每期股票数约 3,600–5,200 只，分层后每层仍有数百只，统计功效足够。
