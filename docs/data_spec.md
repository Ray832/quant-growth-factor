# 数据契约（BigQuant 导出 → 本项目）

- 版本：v1（2026-11-02）
- 目的：把 BigQuant 导出的 CSV 直接喂给复现流水线，避免口径返工
- 原则：**宁可多导原始字段，不要只导成品因子**。因子我来算，口径我来控。

---

## 0. 一句话结论

可行。按下面 6 张表导出即可；最关键是 **财务表必须带 `ann_date`（公告日）**，
以及 **行情表要包含已退市股票**。其余字段名不一致没关系，我给你一份映射配置，改配置不改代码。

## 2. 字段定义

### 2.1 `stock_basic.csv`

| 列 | 说明 | 示例 |
|---|---|---|
| `instrument` | 统一代码，`6位数字.交易所` | `000001.SZ` |
| `name` | 简称 | `平安银行` |
| `list_date` | 上市日 `YYYY-MM-DD` | `1991-04-03` |
| `delist_date` | 退市日，未退市留空 | |
| `board` | 板块（主板/创业板/科创板/北交所），可留空 | `主板` |

### 2.2 `calendar.csv`

| 列 | 说明 |
|---|---|
| `date` | `YYYY-MM-DD` |
| `is_open` | 1/0（可省略，缺省按 prices 出现过的日期推断） |

### 2.3 `prices_YYYY.csv`（核心表）

| 列 | 说明 | 必需 |
|---|---|---|
| `date` | 交易日 | ✅ |
| `instrument` | 代码 | ✅ |
| `close` | 收盘价（**不复权**） | ✅ |
| `pre_close` | 前收盘（可留空，用于算涨跌停） | ○ |
| `adj_factor` | **后复权因子**（或直接给 `close_adj` 后复权收盘价，二选一） | ✅ |
| `volume` | 成交量（股） | ○ |
| `amount` | 成交额（元） | ○ |
| `turnover_rate` | 换手率（小数，如 0.023 表示 2.3%） | ○ |
| `float_mv` | 流通市值（元） | ✅ |
| `total_mv` | 总市值（元） | ○ |
| `is_st` | 是否 ST/*ST（1/0） | ✅ |
| `is_suspended` | 是否停牌（1/0） | ✅ |

**要点**
- 必须含**已退市**股票（否则 2016 年前的回测有生存偏差）。
- 复权只用于算收益；算市值、做分层权重时用**原始价格/市值**。
- 涨跌停标记有就更好（`limit_up`/`limit_down`），没有我用 `pre_close` 自行判定。

### 2.4 `financials.csv`（核心表）

| 列 | 说明 | 必需 |
|---|---|---|
| `instrument` | 代码 | ✅ |
| `report_period` | **报告期**（如 `2016-06-30`） | ✅ |
| `ann_date` | **公告日**（实际披露日，`YYYY-MM-DD`） | ✅ |
| `report_type` | 报表类型（一季报/中报/三季报/年报；或 `1/2/3/4`） | ○ |
| `operating_revenue` | 营业收入，**年初至今累计** | ✅ |
| `net_profit` | 归母净利润，累计 | ✅ |
| `ocf` | 经营活动现金流净额，累计 | ✅ |
| `total_equity` | 归母净资产（期末） | ✅ |
| `total_assets` | 总资产（可选，做辅助校验） | ○ |
| `roe_diluted` | 摊薄 ROE（累计，可选，用来交叉验证） | ○ |
| `or_ttm` / `profit_ttm` / `ocf_ttm` | 若平台已算好 TTM，可一并给（我仍以自算为准） | ○ |

**要点**
- **必须是累计值**（一季报=Q1，中报=H1，三季报=Q1–Q3，年报=全年）。单季值我可以差分出来；
  反过来，只给单季值我拼不出年报口径，会丢精度。
- `ann_date` 缺失是**致命问题**——没有它就无法避免前视偏差。若平台只给报告期，
  请额外导出一张"财报披露日期"表，或在导出时说明该表已按公告日对齐。
- 同一 `(instrument, report_period)` 可能有**更正/重述**，保留多条即可，我按 `ann_date` 取最新。

### 2.5 `industry.csv`

| 列 | 说明 |
|---|---|
| `instrument` | 代码 |
| `industry` | 一级行业名称（申万或东财，注明即可） |
| `start_date` | 该归属生效日（有历史变更最好） |
| `end_date` | 失效日，当前归属留空 |

只给当前快照也能跑，但要在报告里写明"行业分类为当期归属，存在分类漂移"。

### 2.6 `index_000300.csv`

| 列 | 说明 |
|---|---|
| `date` | 月末（或日频） |
| `instrument` | 成分股代码（指数点位行可留空） |
| `weight` | 权重（小数或百分数，注明单位） |
| `index_close` | 沪深300 收盘点位（可单独一张表） |

## 3. 格式约定（省掉 80% 的返工）

1. **编码 UTF-8**（带不带 BOM 都行），逗号分隔，一行表头，不要多层表头、不要合并单元格。
2. 日期统一 `YYYY-MM-DD`，不要 `20160104`、不要 Excel 序列号。
3. **数值用小数，不要百分号字符串**：`0.0523`，不是 `5.23%`。
4. 金额统一**元**，不要"万元/亿元"混用；若必须用万元，在文件名或字典里注明。
5. 缺失留空，不要填 `0`、`--`、`None`、`NaN` 字符串。
6. 代码统一 `000001.SZ` 形式；若平台是 `SZ000001`，给我一份映射说明即可。
7. 按年分片，单个文件控制在 300 MB 以内；能导 parquet 更好（体积小 5–10 倍）。

## 4. 数据量级参考

- 全 A 约 5,000 只 × 2,500 个交易日 ≈ **1,250 万行**；CSV 约 1.5–2.5 GB，分 10 个年文件。
- 财务：5,000 只 × 40 个季度 ≈ 20 万行，几十 MB。
- 我拿到后会立刻转 parquet 并建索引，后续回测读盘秒级。

## 5. 开工前需你确认的 7 件事

1. 财务表的日期列是**报告期**还是**公告日**？有没有单独的 `ann_date`？
2. 数据里**包含已退市股票**吗？（能查一下 2015 年有交易的股票数 vs 现在）
3. 行业分类是**申万一级**还是**东财一级**？有没有历史变更记录？
4. 沪深300 成分是**月度**还是**日度**？权重单位是小数还是百分数？
5. 复权方式：给**后复权因子**还是**后复权价**？
6. 营收/净利/现金流是**累计值**还是**单季值**？
7. 有没有 `is_st`、`is_suspended`、涨跌停标记？

## 6. 我能接受的降级方案

| 情况 | 处理 |
|---|---|
| 只导得出成品因子（如 `fs_operating_revenue_ttm`） | 能做，但 12 个因子的口径由平台决定，报告里要标注"因子由 BigQuant 口径生成" |
| 财务没有公告日 | 用"报告期 + 固定滞后"近似（如年报 4/30、中报 8/31、三季报 10/31），并在附录量化前视偏差 |
| 没有退市股 | 回测存在生存偏差，我会在报告里明确标注，并做"仅存续股票"的敏感性对照 |
| 行业只有当前快照 | 用当前归属回溯，标注分类漂移风险 |

## 7. 拿到数据后的第一步

我会跑 `src/check_data.py`（随数据一起交付），输出一份**体检报告**：

- 各表行数、时间覆盖、股票数、重复主键；
- 财务覆盖度（每季度有多少家公司有数）、`ann_date` 缺失率；
- 行情缺失/停牌/ST 占比；
- 复权因子连续性检查（除权日跳变）；
- 与指数成分的对齐情况；
- 12 个因子在首末截面的非空率。

体检通过后，再进入因子构建，避免"跑到一半发现数据不对"。
