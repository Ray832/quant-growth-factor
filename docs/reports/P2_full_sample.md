## 0. 摘要

本轮把单因子检验从"IC + 5 层"扩展到**回归法、IC 衰减、10 层、分市值、分行业、交易成本**六个维度，全部基于全样本。

**五个关键发现**：

1. **横截面显著，但收益不稳定**：q 因子的 |t| 均值 3.5–4.3（高于原文的 2.5–3.0），但因子收益率序列的 t 值只有 0.84–1.73（原文 2.6–3.5）。说明因子每月都有区分度，但方向年际翻转，长期平均收益不显著。
2. **IC 不衰减**：q 因子 IC 从 t+1 到 t+6 基本持平（ROE_G_q 1.86% → 1.88%），与原文"市场消化很快、当季最优"的解释相反。
3. **3y 因子系统性反向**：IC 从 -0.3% 恶化到 -3.1%（t+6），分层单调性为负。
4. **小盘更强**：ROE_G_q 小盘 IC 2.94%、大盘 1.13%；3y 的反向主要发生在大盘。
5. **扣费后几乎不赚钱**：双边千三后，只有 OCF_G_q 多空净值 +0.5%、夏普 0.15，其余全部转负。

## 3. 方法与公式

### 3.1 回归法（对应原文表 32）

每个月末做一次加权最小二乘：

```
r_{i,t+1} = Σ_j 行业哑变量_j + β · f_{i,t} + ε
权重 w_i = sqrt(流通市值_i)
```

实现用 FWL 等价形式：先按行业做加权去均值，再对残差做单变量加权回归。

| 输出 | 含义 |
|---|---|
| `beta_mean` | 因子收益率均值 |
| `beta_t_stat` | 因子收益率序列的 t 值（是否稳定为正） |
| `abs_t_mean` | 每月截面 t 值绝对值的均值（区分度） |
| `pct_abs_t_gt2` | 截面 t 值绝对值 >2 的月份占比 |
| `t_mean_over_std` | t 值均值 / t 值标准差 |

### 3.2 IC（本轮口径升级）

原文 IC 是"因子对行业 + 市值回归后的残差"与下月收益的相关。本轮按此实现：

1. 因子先去极值、z-score；
2. 每期对**行业哑变量 + ln(流通市值)** 做 OLS，取残差；
3. 残差与下月收益求 Spearman 相关。

> P1 只做了行业中性，本轮加入市值中性，数值会略高，**以本轮为准**。

### 3.3 IC 衰减

对 h = 1…6 个月的前瞻收益分别计算 IC：

```
IC_h(t) = corr(f_t, r_{t→t+h})
```

### 3.4 10 层回测

行业内按因子分 10 层，层内等权；多空 = 第 0 层 − 第 9 层；单调性 = `−spearman(层号, 层均收益)`。

### 3.5 分市值 / 分行业

- 市值：每月按流通市值三分位，组内算 IC，再对月份平均；
- 行业：每月在每个行业内算 IC（≥10 只），再对月份平均。

### 3.6 交易成本

多空组合按**双边千三**扣费（假设每月完全换仓）：

```
净收益 = 毛收益 − 0.3%
```

- 31 个行业中 **27 个 IC 为正**，中位 +2.01%；

## 6. 与原文的关系

| 原文结论 | 本次结果 | 判断 |
|---|---|---|
| 当季 > TTM > 三年 | q 正、ttm 接近 0、3y 负 | **支持且更极端** |
| Profit/ROE > Sales > OCF | ROE/Profit 分层最强，OCF 弱但最稳 | 部分支持 |
| 市场消化快、当季最优 | q 因子 IC 到 6 个月不衰减 | **不支持** |
| 因子收益率显著（t 2.6–3.5） | beta t 0.84–1.73 | **不支持** |
| 3y 基本无效 | 3y 系统性反向 | 不一致 |

**差异解释**（待 P3 验证）：

1. 样本期 2020–2025 经历注册制、退市新规、机构化，成长溢价被压缩；
2. 2021 年基数效应导致同比失真，因子方向年际翻转；
3. 交易成本：原文未扣费，本轮扣费后 alpha 基本消失；
4. 原文 2005–2016 的小市值效应更强，本次小盘 IC 也确实更高。

## 7. 关键结论（可直接写入研报）

1. 成长因子在 2020–2025 **仍有横截面区分度**（q 因子 |t|>3、单调性 >0.8），但**因子收益不稳定**（beta t<1.8），属于"能排序、难赚钱"。
2. **三年复合增长率因子方向反转**，高增长组跑输，提示"高增长陷阱"。
3. **IC 不衰减**，说明原文"市场消化快"的解释在近五年不成立。
4. **小盘更有效**，大盘的 3y 反向最明显。
5. **扣费后几乎无 alpha**，只有 OCF_G_q 微弱为正（+0.5%/年、夏普 0.15）。

> 第 5 条已被 P3 修正：真实换手口径下，q 因子扣费后年化 +2.7% ~ +5.3%。
