**（1）无前视偏差**

## 5. 过程中发现并修复的两个问题

### 5.1 ROE_G_q 与 ROE_G_ttm 写成同一公式

初版两个因子都用净利润 TTM / 净资产算同比，导致数值完全相同。
这类错误不会被"能否跑通"的测试发现，因此：

1. 修正：`ROE_G_q` 改用单季净利润 / 净资产，`ROE_G_ttm` 用 TTM；
2. 加回归测试 `test_roe_q_differs_from_ttm`：要求两者至少 50% 的样本不同。

### 5.2 财报缺失被填成 0，因子出现 -100%

准备讲解示例时发现：`000001.SZ` 从 2025-10 起，`operating_revenue_ttm` 与 `net_profit_ttm` 变成 **0**，而净资产仍在更新。

按公式 `(0 - base) / |base| = -100%`，这类记录会污染截面（全 A 约 1.8% 的月末记录受影响，且集中在每年 10–12 月，即年报尚未披露的窗口）。

**修正**：在因子构建前统一清洗——

| 字段 | 规则 | 理由 |
|---|---|---|
| `operating_revenue_*` | `<= 0` → 缺失 | 营收不可能为负；负值多为重组/追溯调整异常 |
| `net_profit_*`、`net_cffoa_*` | `== 0` → 缺失 | 利润与现金流为负合法，只有 0 是填充值 |
| `total_equity_*` | `<= 0` → 缺失 | 资不抵债时 ROE 无意义 |

并加回归测试 `test_no_zero_fill_artifacts`：12 个因子里等于 -1.0 的比例必须 < 0.1%。

## 6. 已知局限

| 局限 | 影响 | 正式分析如何处理 |
|---|---|---|
| 小样本 80 只 | IC 噪声大，不能作为结论 | 全样本每期 3,600–5,200 只 |
| 分层用等权 | 与研报"行业权重=沪深300"不同 | 已确认降级为全 A 流通市值行业权重 |
| 未扣交易成本 | 多空收益偏高 | 正式回测加双边千三 |
| IC 用原始因子 | 未做市值中性 | 正式分析加行业+市值中性残差 |
| 未做分组显著性检验 | 无法判断 IC 是否显著 | 正式分析加 t 检验、bootstrap |
